# Historical Timeline

## Описание

Этот проект реализует интерактивную историческую временную шкалу с использованием React, TypeScript, GSAP и Styled Components.

Он легко интегрируется в любой сайт, может использоваться несколько раз на одной странице без конфликтов между экземплярами.

## Быстрый старт

1. **Установите зависимости:**
```bash
npm install
```


2. **Запустите проект в режиме разработки:**
```bash
npm start
```

Проект откроется по адресу [`http://localhost:3000`](http://localhost:3000)

3. **Соберите проект для продакшена:**
```bash
npm run build
```
Собранные файлы будут помещены в папку `dist`


### Минимальные требования

- Node.js установлен на вашем компьютере
- npm (входит в Node.js)

---

> Весь блок полностью независим от остальной логики страницы, поэтому если добавить на страницу ещё один такой же блок, их разметка и работа не будут друг другу мешать.

Например, можно сделать так:
```tsx
<HistoricalTimelineWidget />
<HistoricalTimelineWidget />
<HistoricalTimelineWidget />
```
